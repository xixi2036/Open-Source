## B. 明确的风险（未复现）

1. **【高】release 允许全局明文流量，默认服务器是模拟器地址**：`AndroidManifest.xml:31`、`core/AppPrefs.kt:55`、`AuthViewModel.kt:60`。release 用 `networkSecurityConfig` 只对回环/私网放行明文；默认地址按 buildType 区分。
2. **【高】后台时连接看门狗和 HTTP 兜底都不工作**：`core/HushCore.kt:211, 245-246` 要求 `appInForeground`；全工程没有 `NetworkCallback`。看门狗去掉前台条件；网络恢复时 `start()`/`syncNow()`。
3. **【高，需真机验证】息屏后长连接可能失活**：声明了 `WAKE_LOCK` 但未使用；无电池优化白名单引导；无 `BOOT_COMPLETED`。
4. **【中】通知权限被拒时后台来电无任何提示，应用内无引导**：`service/Notifier.kt:133-135,194-196`、`ui/HushRoot.kt:96-104`、`me/MeScreen.kt:140`。
5. **【中】同一会话通知只响一次**：`Notifier.kt:127` `setOnlyAlertOnce(true)` + 固定 id。
6. **【中】来电只响铃不振动，铃声未显式循环，去电无回铃音**：`ui/call/CallAudio.kt:75-80`。
7. **【中】语音通话没有距离感应熄屏**。
8. **【中】通话没有 ICE 重连**：`CallManager.kt:549` 只处理 `FAILED`。
9. **【低】双方同时互拨时两边都显示"对方忙线中"**：`CallManager.kt:297-299`；按 user_id 大小决定谁让步。
10. **【中】附件下载失败后永久转圈**：`ui/chat/MessageBubble.kt:300-307,328`、`ChatViewModel.kt:187-201`；自动下载不区分计量网络。
11. **【低-中】新消息只追加到末尾，不按 `sort_ts` 排序**：`ChatViewModel.kt:139-141,149-150,332-336`。
12. **【中】屏幕锁开启但"屏幕安全"关闭时最近任务缩略图仍显示聊天内容；关闭屏幕锁不需要验证**：`MainActivity.kt:30-32`、`MeScreen.kt:125-133`。
13. **【低-中】事件总线溢出会丢事件，聊天页无法自愈**：`HushCore.kt:44`、`ChatPaging.kt:21`。
14. **【低】透明 PNG 被压成 JPEG、GIF 不动、视频附件空白**：`ChatViewModel.kt:347-348`、`MessageBubble.kt:205`。
15. **【低】登出后聊天页 ViewModel 不释放**：`HushRoot.kt:107-111`。

## C. 需要实测验证的优化项

1. 会话列表每个事件都全量重载（`chats/ConversationListViewModel.kt:40-45,64-74`）：300–500ms 防抖，归档数单独缓存。
2. 资料/媒体缓存整表复制（`core/ContactsStore.kt:51-61`、`MediaCache.kt:34`）：批量合并后一次发射。
3. 聊天列表每次消息变化重建全部行（`ChatScreen.kt:109`）；`MessageItem` 非稳定类型。用 Macrobenchmark 量滚动掉帧。
4. 启动：没有自有 Baseline Profile；v3/v4 迁移首次打开时启动页无进度提示。
5. release APK 30MB 构成：WebRTC so 12.3MB、hushcore so 7.95MB、ML Kit 条码 4.3MB、dex 2.6MB；x86_64 合计约 12.8MB。建议 release 去掉 x86_64 或按 ABI 拆包；确认 `useLegacyPackaging` 是否仍需要；条码改用 ZXing 解码可省约 4MB。
6. 图片查看器：平移无边界，放大后发虚，不能左右滑动切图。
7. 语音录制：无最长时长、无振动反馈；按住手势 TalkBack 无法操作。
8. 搜索：每次输入触发核心全量解密，结果不分页、不高亮。
9. 通知跳转：进程被杀后从最近任务恢复会再次跳进该会话；删除会话未取消其通知。
10. 平板/折叠屏：单栏拉伸，无列表-详情双栏。

迭代与架构：界面中文全部硬编码（`strings.xml` 仅 35 条）；全局 `object` 多、ViewModel 直接访问 `HushCore.client`，缺 `androidTest`；搜索框与权限申请逻辑多处重复；`targetSdk=36`/`compileSdk=37`、`versionCode=1` 固定、无签名文件时回退 debug 签名有误发风险、缺 `dataExtractionRules`。
